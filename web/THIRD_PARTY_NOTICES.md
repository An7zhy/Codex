# Third-party components

This interface contains original application code, copy and SVG artwork.
It does not contain project44 logos, photographs, downloaded assets or copied layouts.

Dependencies are declared and locked in package.json/package-lock.json. Their
upstream licenses apply: Next.js, React, Tailwind CSS, Radix UI, class-variance-authority,
clsx, tailwind-merge, Recharts and Motion use permissive open-source licenses;
Lucide icons use ISC. Manrope, distributed via @fontsource-variable/manrope,
uses the SIL Open Font License 1.1. The package retains its upstream license.

The local Button/Dialog conventions are shadcn-compatible, using owned source and
Radix primitives. No proprietary component kit or paid asset service is required.
