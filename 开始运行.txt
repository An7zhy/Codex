Logistics Insight AI — Sprint 2.5 本地完整版

这个版本包含 V1/V2/V3、新官网、上传优化、决策历史和设置并发修复。
默认启动的是可操作的受保护完整应用。请先使用 Synthetic Demo Data 测试。

Windows 首次启动

1. 安装 Python 3.12 和 Node.js 24 LTS，然后重新打开终端。
   Python: https://www.python.org/downloads/
   Node.js: https://nodejs.org/
   已有 Python 3.14 可以保留；本项目本轮实际验证使用 Python 3.12。

2. 解压到全新的文件夹，例如 D:\Logistics-Insight-AI-Sprint-2.5。
   找到 start-web.bat、requirements-web.txt、backend 和 web 都在的这一层。
   不要双击 app.py；那不是新版网站的启动方式。

3. 在该文件夹的资源管理器地址栏输入 cmd，按回车。
   在弹出的命令提示符中逐行输入以下两行；每行输入后按回车并等待完成：

   py -3.12 -m venv .venv
   start-web.bat

   第一行固定使用已测试的 Python 3.12，避免电脑默认选到其他版本。
   如果提示找不到 Python 3.12，请先完成第1步，不要在 Python 的 >>> 窗口输入命令。

4. 第一次启动会联网安装依赖、构建网站，并提示创建：
   Organization name：你自己的组织名称，例如 My Logistics Lab
   Administrator account name：你自己设置的账号，例如 student
   New password / Repeat password：自己设置并重复输入，至少12个字符
   输入密码不显示字符是正常现象。压缩包没有默认账号、密码或旧数据库。

5. 等终端显示 Website: http://127.0.0.1:3000，浏览器通常会自动打开。
   也可以手动访问 http://127.0.0.1:3000。
   点击 Launch platform，用第4步创建的账号登录。
   使用时保持终端打开；结束时在该终端按 Ctrl+C。

以后启动

在项目目录的 cmd 中输入：
   .venv\Scripts\python.exe -m scripts.start_web --open

简单测试顺序

- Overview：默认分析日期2026-10-01，对照158单、47.8%准时率、30单运输中逾期。
- Shipments / Exceptions：测试筛选、异常解释和下载。
- Settings：修改权重并保存，查看版本；多会话冲突会返回409并要求重新加载。
- Decision Center：比较假设方案、保存决策；历史页更新处理状态。
- Optimization：Synthetic Demo Mode可运行模拟优化。
- Optimization：Uploaded Data Mode下载100单合成模板，上传、预览、确认、求解、下载。
- Analytics：查看已有优化结果及相应来源/假设；上传模式不提供虚构的真实逾期概率。
